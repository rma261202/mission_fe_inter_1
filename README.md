# Mission Frontend Advance 1 - Chill Movie App

Website ini dibuat menggunakan React + Vite.
Fitur yang tersedia:
- Create Movie (Modal Form)
- Read Movie (Fetch from API)
- Update Movie (Edit Existing Data)
- Delete Movie (Remove from API)

## Environment Variable
Berikut adalah Base URL MockAPI yang digunakan dalam project ini:

`VITE_API_BASE_URL=https://693fd4c0993d68afba69de83.mockapi.io/api/v1`

## Cara Menjalankan
1. Clone repository
2. `npm install`
3. `npm run dev`
